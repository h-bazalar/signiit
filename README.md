# Signiit

Creativos con intención para tus anuncios.

## Setup

```bash
# Instalar dependencias
npm install

# Copiar variables de entorno
cp .env.example .env.local
# → Editar .env.local con las keys reales

# Dev
npm run dev

# Build
npm run build
```

## Stack

- React 18 + Vite
- Tailwind CSS
- Clerk (auth)
- Supabase (PostgreSQL)
- Vercel (deploy + API routes)
- n8n (pipelines IA en VPS)

## Variables de entorno

Ver `.env.example` para la lista completa.
